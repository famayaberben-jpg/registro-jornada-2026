# 📱 Registro de Jornada Laboral 2026

Una aplicación móvil completa para registrar y gestionar tus horas de trabajo diarias.

## ✨ Características

✅ **Registra tus jornadas diarias** - Agregar, editar y eliminar horas trabajadas
✅ **Historial completo** - Navega por meses y ve todos tus registros
✅ **Estadísticas detalladas** - Analiza tus horas mensuales y anuales
✅ **Exporta a Excel** - Descarga todos tus datos en formato Excel
✅ **Almacenamiento local** - Tus datos están seguros en tu dispositivo
✅ **Interfaz intuitiva** - Diseño moderno y fácil de usar

## 🚀 Pantallas Principales

### 1️⃣ **Inicio (Home)**
- Resumen de horas del mes actual
- Últimas 5 jornadas registradas
- Botón flotante para agregar nueva jornada

### 2️⃣ **Agregar/Editar Jornada**
- Selector de fecha
- Ingreso de horas trabajadas
- Vista previa del registro
- Validación de datos

### 3️⃣ **Historial**
- Navega entre meses
- Visualiza todas tus jornadas
- Total de horas del mes
- Edita o elimina registros

### 4️⃣ **Estadísticas**
- Total de horas por año
- Horas del mes actual
- Promedio de horas por día
- Desglose mensual visual
- Navega entre años

### 5️⃣ **Exportar**
- Descarga todos tus registros en Excel
- Compatible con Excel, Google Sheets y LibreOffice
- Respaldo de seguridad de tus datos

## 📋 Requisitos

- Node.js y npm instalados
- Expo CLI instalado (`npm install -g expo-cli`)
- Dispositivo móvil con Expo Go instalado (iOS/Android)

## 🔧 Instalación

1. **Clona el repositorio**
```bash
git clone https://github.com/famayaberben-jpg/registro-jornada-2026.git
cd registro-jornada-2026
```

2. **Instala las dependencias**
```bash
npm install
```

3. **Inicia la aplicación**
```bash
expo start
```

4. **Abre en tu dispositivo**
   - Escanea el código QR con Expo Go (iOS o Android)
   - O presiona `i` para iOS o `a` para Android en la terminal

SQLite local - Todos tus datos se guardan en tu dispositivo.

## 💡 Consejos de Uso

- Registra diariamente para mantener un historial preciso
- Usa decimales: 8.5 = 8h 30min
- Meta mensual: 160 horas
- Meta anual: 1,920 horas
- Exporta regularmente como respaldo
